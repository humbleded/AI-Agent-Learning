## 固定口令

### `开始今天的学习` / `开始今天的学习计划`

两个口令兼容保留，含义都是“当前知识单元预览”。预览必须给出：

- 当前任务与前置证据；
- 已核验的资料入口和本单元范围；
- 本单元产物、PASS 标准与未覆盖边界；
- 当前 Session 起点与下一口令。

预览不教学、不出题、不创建未来文件，也不把 `TODO` 改成 `DOING`。

### `开始带读` / `开始动手`

这两个口令启动实际 Session。启动时才创建或更新当天 daily、链接该任务所有前序 daily，并按需要把任务从 `TODO` 改成 `DOING`。Session 可以当日结束，也可以跨日期接力；新日期从上一 Session 的明确起点继续。

### `开始今天的练习`

名称兼容保留。正式题集按任务级覆盖缺口生成，跨日期不清零；已 PASS 的即时考察不得换措辞重复。概念/阅读任务总覆盖仍以 8–12 个有效考察为上限，编码/Gate/项目以 5–8 个高质量检查点和真实产物为主。

### `检查今天的学习`

继续触发正式验收及授权后的知识库同步。核验对象是该任务全部 Session、全部关联 daily 和真实产物，不只检查当天。

## Session 接力规则

每个实际 Session 必须维护：

1. `本 Session 目标`：此次只推进哪个可收口的知识或产物切片。
2. `本 Session 已覆盖`：可定位的原始回答、代码、命令、测试或 trace。
3. `本 Session 未覆盖`：当前切片尚未完成的内容。
4. `任务总剩余`：跨 Session 仍未满足的全部 rubric。
5. `下次 Session 起点`：未来启动时的第一个具体动作。

换日期不重置即时题、正式题、算法配额、RETRY、弱点或证据。只有真实开始才写 Session；计划预览不制造证据。
