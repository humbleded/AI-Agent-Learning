# 每日学习计划

配合 `weekly-plan.md` 使用。**核心：任务是有顺序的队列，但不绑死日期——每个学习日从 `tracker/progress.md` 看做到哪，往下拉下一个没做的任务。** 哪天做、做几个，看当天状态；有事耽误提前跟我说，那天顺延、任务吸收到后面，连续性优先。

不再按周一到周日把强度排死（废弃「周一周五特别轻」「满血 / 半血 / 空血」这类按具体星期定档），**但保留「工作日小块推进 / 周末整块攻关」的任务类型分工**——见下「二、固定规则」。

## 一、每天的节奏

- **主块**：当天的主任务——从 `progress.md` 往下拉下一个（概念阅读 / 写代码 / 过 Gate / 项目）。
- **碎片阅读**：白天有空就用手机读当天的纯阅读项（中文文档 / 笔记 / 视频段落），不写代码、不依赖电脑；没读懂的下班整块时间我带你导读。
- **收尾**：1 道算法（第 4 周起）/ 复习昨天 / 写几行笔记 / 更新当天 `daily` 打卡。
- 你超前时不必硬塞满；**连续性比单日强度重要**，哪怕只推进一点、写一行打卡，也别断。

## 二、几条固定规则（其余跟着队列走）

1. **Gate / 项目 / 部署 → 周末做**：要整块连续时间。判据是「**能否一坐做完、不留半成品过夜**」——工作日**可**做能起能收的自包含单元（小脚本 / 单函数 / 小实验，如 S-03 的 token 对比），但**不碰**会停在「跑一半、明天得重新捡上下文」的活（Gate 收尾 / 大整合 / 大 debug / 部署）。「Gate 和项目宁可慢，不要带着跑不通的代码往后走」。
2. **周复盘 / 阶段总结 → 周末做**：要回看整周 / 整阶段，沉淀进 `D:/AI-Knowledge/07-Reviews/`，和周末的大任务搭在一起。**周末时间不够时按此优先级保**：项目跑通 > debug 收尾 > 周复盘 > 知识库沉淀 > 下周预习；但**沉淀留一条保命线**——哪怕只 15 分钟，也要把本周最硬的那个坑 / 结论写进 `D:\AI-Knowledge`，这条不可被挤掉（否则「学得多、沉淀跟不上」就复发）。
3. **每日小结跟着任务走**：daily 文件里的「当天 / 总进度小结、问答点评」等，是「检查今天的学习」当天顺手回填的，**不攒到周末**。
4. **工作日遇到「下一个是 Gate」**：因为 Gate 要等周末，工作日就拉 **gate 无关的项**填上——B0 工程基础穿插补课 / 下一阶段的概念预习——别空等。
5. **关前周五做「设计准备」**：周末要闯的 Gate，可在前一个工作日先规划结构、列函数、重读相关代码（**只设计不写实现**），让周末跑得顺。
6. **强制顺序关卡**（`P0-Gate`、`L1-Gate`、`T3-Gate`、`A4-Gate`、`R6-Gate`、`G8-Gate`、`M9-Gate`、`FINAL-Gate`）没过，不进入后续同类阶段的**动手交付与该阶段 Gate**；其前的工作日按第 4 条填充（概念预习 / B0 穿插不受限）。
7. **算法 W4 起每周必滚（≥3 题，不可静默跳过）**：算法不是 Gate、最容易「计划里有但没人管」，钉成固定规则——每周至少 3 题，哪周漏了下周补。它是应用岗面试的真过滤器，别留到求职冲刺周才从零开始。
8. **作品集分两档（别镀金玩具 Gate）**：玩具级 Gate（如 PR2-Gate 邮件处理器）只上「轻量卫生」= README + `.env.example` + 几条测试输入 + 干净 commit；**全套打磨**（截图 / demo / 写作 / 失败日志）只留给 3–4 个锚点项目（A4-Gate①、R6-Gate②、G8-Gate③、FINAL④）。

## 三、顺延规则

- 不预设机动日、不预设降档。哪天加班 / 有事，**提前告诉我，那天顺延**，任务挪到后面。
- 没特别说的日子一律正常排任务、照常出题。

## 四、任务从哪来 + 当前队列

每天该学什么，三个文件对齐：`weekly-plan.md`（W1–W16 阶段 → 任务）+ `progress.md`（做到哪）+ `ai-agent-learning-tracker.md`（该任务的资料 / 要做 / 通过标准 / 必答问题）。

**当前进度**：阶段 0 全 PASS；阶段 1 `L1-01`~`L1-05` 全 PASS。

**接下来的队列（顺着拉，不钉日期）**：

```text
[工作日填充] PR2-01 Prompt 概念预习 / B0 穿插补课（L1-Gate 要周末，工作日先做这些）
[周末] L1-Gate API 入门闯关   ← 阶段1 收尾整合关，过了才正式进阶段2 动手
   ↓
PR2-01 动手(3 个 prompt 对比) → PR2-02 摘要 → PR2-03 分类 → S-03 上下文工程 → PR2-04 JSON/Schema
[周末] PR2-Gate 邮件处理器     ← 阶段2 收尾关
   ↓
阶段 3（Tool Calling）起，逐周任务见 weekly-plan 第四节 W4–W16
```

> 用法：每天开「学习计划」时，照 `progress.md` 找到队列里下一个没做的；若它是 Gate 就按规则 4 拉填充项，把 Gate 留给周末。

## 五、提醒

- 每天用 `daily/YYYY-MM-DD.md` 打卡：学完用 `daily-practice-builder` 出题，检查用 `ai-agent-learning-review` 判定并回填（**每日小结即在此回填**）。
- 周末除了 Gate / 项目，记得做一次**周复盘**沉淀进 `07-Reviews/`。
- 有事耽误就主动说，**顺延是计划内的，不是失败**。
