# 复习与易错点台账（统一排期）

本文件是旧知识复习排期的**唯一事实源**，统一保存 🔴/🟡 活跃错题、📌 核心定义间隔项和 ✅ 稳定错题间隔项。出题时从这里挑“该翻旧账复习”的目标；不要再建一套独立日历卡片。

原始作答与订正明细在 `daily/YYYY-MM-DD.md`，任务状态在 `tracker/progress.md`，完整正确内容在项目 `notes/` 和授权后的 `D:\AI-Knowledge`。本表只留最小语义目标、证据链接与排期，不复制完整答案。

## 状态与「间隔回炉」（关键：✅ 不等于永不再考）

- 🔴 **还容易错**：持续在候选池，按当前任务相关性和最久未测排序；不需要伪造“下次回炉日”。
- 🟡 **订正过一次**：持续候选，待下一次独立证据；答对 → 升 ✅，首个回炉日为本次 PASS `+2周`；答错 → 打回/保留 🔴。
- 📌 **核心定义间隔项**：只收任务正式 PASS 后、去重后的 `must-recall`。首个回炉日为任务 PASS `+2周`；答错时移出本池并合并/新增为 🟡 活跃弱点。
- ✅ **稳定错题间隔项**：按「下次回炉」日期到期抽查。
- 两类间隔项抽查**答对**后依次升档：`+1月 → +2月 → +3月封顶`，此后每 3 个月一次；抽查**答错**则回到活跃 🟡 并重置间隔。同一语义不得同时占活跃池和间隔池。

一句话：核心定义和错题共用一张排期表、共用当天最多 2 项的旧复习预算；熟了拉长间隔，答错立即回到活跃池。

## 怎么维护（我在「检查/出题」这两步自动做，你不用手填）

- **出题时（拉取式）**：只有用户启动练习时才扫描三池；任何一天旧复习目标**总计最多 2 个**，概念/阅读日默认 1 个，编码/Gate/项目日通常 0–1 个且必须关联真实产物。先看与当前任务的语义相关性，再比较活跃项的最久未测和间隔项的逾期程度；一个题能同时覆盖当前标准和旧目标时合并计算，不叠加题量。
- **积压阈值**：到期的 📌/✅ 间隔项达到 4 个，或最老一项逾期达到 7 天时，先连续两次练习优先使用上述既有旧复习席位，不立即增加题量；若两次后仍高于阈值，才在后续 ≤180 分钟日计划内安排一个 20–30 分钟回收块，每天最多一个，并替换部分主块而非追加到预算外。
- **不制造假债务**：🔴/🟡 活跃池持续可选，但没有“到期日”，不计入上面的逾期数量/天数；只有 📌/✅ 间隔池参与积压阈值判断。
- **批改/正式检查时**：新增或合并当天的坑/最虚，记录原始证据；正式检查者按上面的升降档规则更新池、上次证据与间隔日期。
- **提醒边界**：本台账不会自行弹窗或后台运行。除非用户另行明确要求自动提醒，否则不创建系统日历/自动化；到期项会在下一次“开始今天的练习”时被拉取。
