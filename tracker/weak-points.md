# 易错点台账（错题本）

出题时**优先从这里挑「该翻旧账复习」的点**。
明细在 `daily/YYYY-MM-DD.md` 和 `tracker/progress.md`，本表只放一句话索引。

## 状态与「间隔回炉」（关键：✅ 不等于永不再考）

- 🔴 **还容易错**：每套练习都在候选池，重点出。
- 🟡 **订正过一次**：近几套内再独立考一次；答对 → 升 ✅ 并设首个回炉日；答错 → 打回 🔴。
- ✅ **已稳定 = 进入间隔回炉，不是封存**：按「下次回炉」日期到期抽查一道。
  - 抽查**答对** → 间隔升档、刷新下次回炉：`+2周 → +1月 → +2月 → +3月封顶`（此后每 3 月抽查一次，永远留个尾巴，不会彻底丢）。
  - 抽查**答错** → 打回 🟡，回炉清零，重新走闭环。

一句话：熟了就把间隔拉长，但**永远保留一次「回炉抽查」**；一旦手生答错，立刻拉回高频复习。

## 怎么维护（我在「检查/出题」这两步自动做，你不用手填）

- **出题时（我知道今天日期）**：先扫 🔴/🟡（每套至少带 1 道命中）；再扫 ✅ 表里「下次回炉 ≤ 今天」的项，挑**最逾期的 1–2 道**塞进去抽查（到期的多了就先挑最逾期的，不一次全考）。
- **批改时**：新增当天的坑/最虚；按上面的升降档规则更新状态、上次测、下次回炉。
