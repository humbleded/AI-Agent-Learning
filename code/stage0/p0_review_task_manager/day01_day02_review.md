参考强化版：

Q2：如果用户输入任务编号 100，程序可能出什么问题？

答：如果没有先检查编号范围，程序会访问不存在的列表位置，比如 `tasks[index - 1]` 或 `pop(index - 1)`，可能触发 `IndexError`。当前代码已经做了范围判断，所以不会崩溃，但会静默不处理；更好的做法是提示用户“编号不存在”，或者让函数返回 `True/False` 表示操作是否成功。

Q3：为什么菜单输入逻辑应该主要放在 `main()`，而不是分散到每个函数里？

答：`main()` 负责和用户交互、读取输入、决定调用哪个函数；其他函数只负责具体任务操作。这样函数更容易复用和测试，例如可以直接调用 `add_task(tasks, name)`，不用每次都依赖 `input()`。如果把输入逻辑分散到每个函数里，函数会和命令行界面绑得太死，后面改成文件、网页或自动测试都会更麻烦。
