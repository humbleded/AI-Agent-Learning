## 原始理解与订正

| 用户原话或原意 | 当前准确结论 |
| --- | --- |
| “低温稳，高温野。” | 温度较低时偏向高概率选择；较高时概率差距更平缓，输出更容易变化。质量是否变好要看任务与实测。 |
| 起名低／高都行，看要经典还是发散；写代码选低温 | 参数选择应对应任务目的。低温通常降低随机性，但不保证代码正确，也不保证相同输入每次得到完全相同的输出。 |
| “回答会变得更随机。” | 原订正进一步指出：温度改变候选的概率分布；提高温度会使低概率候选更容易被选中。 |
| 成本是输入（system＋历史＋本轮）加输出 | 还需区分缓存命中与未命中的输入用量及其单价。价格与计费项目以调用时的官方说明为准，不把历史单价当当前价格。 |

原 daily 曾把“低温保证可复现”判为正确，本页将该知识结论收窄为“降低随机性，不保证逐字一致”；原始作答、订正经过与历史判定仍保留在 daily，不据此次文档维护重判整项课程。
