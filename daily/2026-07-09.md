## B. 解释与比较

**B1** 为什么说：“有 Tool Calling” 不一定等于 “已经是多步 Agent”？请用 Observation 和“是否继续循环”来解释。

```python
# 用户答：
# 因为Agent会根据Observation的结果来判断是把结果返回给用户还是继续调用工具直到完成目标。所以只是调用了工具，没有后续如果结果不符合预期后会继续调用工具这个环节，就不能说是等于多步 Agent。
# 判定：PASS
# 补充：准确。Tool Calling 解决“模型如何表达要调用哪个工具和参数”；多步 Agent 还要求客户端把 Observation 回填后，让模型判断目标是否完成，未完成则进入下一轮 Thought -> Action -> Observation。
```
