## B. 解释与比较

**B1** 为什么 PR2-Gate 里不能“手拼 JSON 字符串”，而要先组装 Python `dict`，最后交给 `json.dump` 保存？请说 2 个理由。

```python
# 用户答：
# 1.人为拼写容易出错
# 2.先组装 Python dict可以先代码验证返回的结果是不是正确且标准的JSON，没问题然后在写入文件中，保证正确
# 判定：PASS
# 补充：dict 本身不是“标准 JSON”，它是 Python 数据结构；json.dump 会把可序列化的 dict/list/str 等对象写成合法 JSON。
# 核心理由：手拼容易漏引号/逗号/转义；dict 能先做字段/类型校验，再由标准库负责生成合法 JSON。
```

**B2** `prompt` 里写“必须输出 JSON、字段缺失填 null、不许编造”，和代码里的 `validate_payload(todo)` 分别解决什么问题？为什么不能只靠其中一个？

```python
# 用户答：

# prompt 是解决模型返回格式问题，validate_payload是做验证。如果只靠prompt ，返回值有可能会有问题。，所以需要两个一起来控制输出

```
