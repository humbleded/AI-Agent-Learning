1. list 和 dict 的最大区别是什么？
   你的答案：list 存一个一个的值，dict 存键值对。
   点评：基本正确。更完整的说法是：list 适合保存有顺序的一组元素，通常用下标或遍历访问；dict 适合用唯一 key 映射到 value，适合按 key 快速查询结构化状态。

2. 为什么 dict 适合保存结构化状态？
   你的答案：dict 通过键值对保存数据，键不可重复，可以通过键快速找到值。
   点评：方向正确。可以再补一句：任务状态这类数据天然是“任务名 -> 状态”的映射，所以 dict 比两个 list 更不容易错位。

3. set 去重的代价是什么？
   你的答案：可能丢失重复数据，且每个元素需要有哈希索引，需要占用额外的内存空间。
   点评：这次修正到位。还可以补充一点：set 不适合表达重复次数和稳定顺序，适合做去重和成员判断。

Codex 超前内容提示：哈希表、时间复杂度、可哈希对象属于后续更深入的数据结构知识；当前阶段只需要知道 set 适合“去重/成员判断”，但不适合保存顺序、重复次数或复杂可变对象。
