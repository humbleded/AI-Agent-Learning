**C3** 写 mini-Compaction `compact_history(history, keep_recent, summarize)`。
```python
# 用户实现（正确、可运行）：
def compact_history(history, keep_recent, summarize):
    if len(history) <= keep_recent:
        return history                      # 主动加的边界守卫（加分）
    old_history = history[:-keep_recent]
    old_text = "\n".join([msg["content"] for msg in old_history])
    summary_text = summarize(old_text)
    summary_message = {"role": "system", "content": "之前对话摘要：" + summary_text}
    return [summary_message] + history[-keep_recent:]
# 判定 PASS（建议：old_text 可带 role；⚠️坑：keep_recent=0 时 history[-0:]==整个列表）
```
